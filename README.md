# Rustlings Plus 🦀

[![Check](https://github.com/aianov/rustlings-plus/actions/workflows/rust.yml/badge.svg)](https://github.com/aianov/rustlings-plus/actions/workflows/rust.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Курс из маленьких задач по Rust в терминале: от основ языка до своих HTTP и WebSocket движков
на tokio, gRPC микросервисов, NATS, PostgreSQL, ScyllaDB и Redis. По ходу курса ты строишь
с нуля свою мини-соцсеть.

## Установка

### Что нужно

| что | зачем | как поставить |
|-----|-------|---------------|
| Rust 1.88 или новее | всё | [rustup.rs](https://rustup.rs), потом `rustup update` |
| git | установка из репозитория | обычно уже есть |
| Docker с `docker compose` | разделы про базы данных, NATS и микросервисы | [Docker Desktop](https://www.docker.com/products/docker-desktop/) или Docker Engine |
| protoc | главы про gRPC | `brew install protobuf` или `apt install protobuf-compiler` |

Для первых разделов хватит одного Rust. Docker и protoc можно поставить потом, когда дойдёшь до них.
Работает на macOS и Linux.

### Поставить Rustlings Plus

```bash
cargo install --git https://github.com/aianov/rustlings-plus --locked rustlings
```

`rustlings` в конце команды это имя пакета: без него cargo запутается в проектах из упражнений.
Бинарник тоже называется `rustlings`. Если у тебя уже стоит обычный Rustlings, добавь `--force`,
и новая версия заменит старую:

```bash
cargo install --git https://github.com/aianov/rustlings-plus --locked rustlings --force
```

Можно и из клона, если хочешь сразу видеть исходники:

```bash
git clone https://github.com/aianov/rustlings-plus
```

```bash
cd rustlings-plus && cargo install --path . --locked
```

### Создать папку курса

Перейди туда, где будет лежать твоя работа, и запусти:

```bash
rustlings init --lang ru
```

Появится папка `rustlings/` со всеми задачами. Язык можно выбрать `ru` или `en`
и сменить позже командой `rustlings lang`.

```bash
cd rustlings
```

```bash
rustlings
```

Всё, курс запущен. Открой папку `rustlings/` в редакторе (лучше всего VS Code с rust-analyzer)
и решай задачу, путь к которой показан на экране.

### Поднять сервисы (когда понадобятся)

В папке `rustlings/` уже лежит `docker-compose.yml` с PostgreSQL, ScyllaDB, NATS и Redis:

```bash
docker compose up -d
```

Проверить, что всё на месте (Rust, Docker, сервисы, protoc, место на диске):

```bash
rustlings doctor
```

### Обновление

Поставь свежую версию той же командой с `--force` и запусти `rustlings` в своей папке.
Новые задачи и исправления подтянутся сами, а файлы, которые ты уже правил, останутся как есть.

```bash
cargo install --git https://github.com/aianov/rustlings-plus --locked rustlings --force
```

## Как пользоваться

### Режим наблюдения

`rustlings` без аргументов открывает режим наблюдения. Сохраняешь файл задачи, и Rustlings
сам пересобирает её и прогоняет тесты. Когда всё зелёное, он предлагает идти дальше.

В каждой задаче есть ошибка компиляции, падающий тест или пустое место, которое нужно дописать.
Теория главы лежит в `README.md` рядом с задачами. Застрял: жми `h`, каждое нажатие открывает
следующую ступень подсказки.

| клавиша | что делает |
|---------|------------|
| `n` | следующая нерешённая задача |
| `h` | подсказка (ещё раз: следующая ступень) |
| `l` | весь курс списком |
| `d` | сравнить своё решение с эталоном (после решения) |
| `v` | анимированные схемы главы |
| `b` | эталон предыдущей вехи для сквозного проекта |
| `x` | сбросить задачу к исходному виду |
| `t` | сменить язык |
| `q` | выйти |

В вопросах цифры выбирают вариант. Если верных несколько, отметь их и нажми `Enter`.
Свободный ответ вводится после `a`. На экзаменах подсказок нет, а эталон открывается после сдачи.

В списке: стрелки или `j`/`k` двигают курсор, `Enter` или `c` открывают задачу, пробел и `←`/`→`
сворачивают главы, `Tab` переключает раздел, `s` ищет, `d`/`p` фильтруют решённые и нерешённые.

Цвета везде одни: зелёный значит решено, красноватый значит начато, но не доделано,
серый значит ты сюда ещё не дошёл.

### Команды

| команда | что делает |
|---------|------------|
| `rustlings` | режим наблюдения за текущей задачей |
| `rustlings list` | весь курс деревом: раздел, глава, задача |
| `rustlings mode [id]` | выбрать, как идти по курсу (см. ниже) |
| `rustlings track [id]` | список разделов или переход к первой нерешённой задаче раздела |
| `rustlings open <name>` | сделать задачу текущей |
| `rustlings run [name]` | проверить задачу, без имени текущую |
| `rustlings hint [name]` | подсказка, каждый вызов открывает следующую ступень |
| `rustlings answer <name> <ответ>` | ответить на вопрос: номера вариантов или текст |
| `rustlings diff [name]` | сравнить решённую задачу с эталоном |
| `rustlings review` | интервальное повторение: несколько давно решённых задач заново |
| `rustlings reset <name>` | вернуть задачу к исходному виду |
| `rustlings check-all` | проверить все задачи и обновить прогресс |
| `rustlings journey status` | прогресс сквозного проекта |
| `rustlings journey baseline <веха>` | начать проект с эталона предыдущей вехи, текущая папка уйдёт в бэкап |
| `rustlings lang [en\|ru]` | показать или сменить язык, твои правки сохраняются |
| `rustlings doctor` | проверить окружение |
| `rustlings migrate` | перенести папку от старого Rustlings в новую раскладку, сначала делается бэкап |

### Режимы

`rustlings mode` спрашивает, чем ты хочешь заниматься:

| режим | что внутри |
|-------|------------|
| `story` | весь курс по порядку: главы, проекты, квизы, а между ними вехи соцсети |
| `social` | только вехи сквозного проекта, у каждой видно, какие темы пройти перед ней |
| `sql` | только PostgreSQL: запросы, схема, транзакции, sqlx, индексы, миграции |
| `cql` | только ScyllaDB: CQL, моделирование под запросы, драйвер на Rust |

Порядок задач только рекомендация: любую главу можно открыть в любой момент через список.

### Сервисы и адреса

Задачи берут адреса из переменных окружения, а без них используют значения из `docker-compose.yml`:

| сервис | по умолчанию | переменная |
|--------|--------------|------------|
| PostgreSQL | `postgres://rustlings:rustlings@127.0.0.1:55432/rustlings` | `RUSTLINGS_PG_URL` |
| ScyllaDB | `127.0.0.1:59042` | `RUSTLINGS_SCYLLA_URI` |
| NATS | `nats://127.0.0.1:54222` | `RUSTLINGS_NATS_URL` |
| Redis | `redis://127.0.0.1:56379` | `RUSTLINGS_REDIS_URL` |

Порты нестандартные, чтобы не мешать твоим локальным базам. Если нужный сервис не отвечает,
Rustlings не запускает сборку и подсказывает, какой контейнер поднять.

### Что лежит в папке курса

```text
rustlings/
├── Cargo.toml                  воркспейс, все сборки идут в общий target/
├── tracks/<раздел>/            пакет раздела, бинарники указывают на файлы задач
├── exercises/<раздел>/<глава>/ теория (README.md), задачи, проекты, схемы
├── solutions/                  эталоны, появляются, когда задача решена
├── backend/                    твоя соцсеть, появляется с первой вехой
├── support/                    помощники для тестов с базами и NATS
├── docker-compose.yml          окружение для задач с сервисами
├── .rustlings-state.txt        текущая задача и прогресс
└── .rustlings-settings.toml    язык и настройки
```

Хочешь начать заново: удали папку `rustlings/` и запусти `rustlings init` ещё раз.

## Что это такое

Rustlings Plus вырос из [Rustlings](https://github.com/rust-lang/rustlings): тот же формат
«исправь код, пока не соберётся и не пройдут тесты», только курс доходит до настоящего бэкенда.
Каждая задача учит одной новой вещи, а теория лежит рядом, так что книгу открывать не обязательно.

### Разделы

| раздел | о чём | глав |
|--------|-------|------|
| Основы Rust | классические задачи Rustlings: синтаксис, владение, трейты, итераторы, потоки, async | 25 |
| Rust углублённо | Cargo и воркспейсы, инструменты, паттерны, замыкания, трейты и обобщения, времена жизни, умные указатели, serde, коллекции, конкурентность, unsafe, Pin и Future, макросы, тесты, производительность | 20 |
| Tokio и async | рантайм, задачи, время, синхронизация, каналы, select и join, async трейты, акторы, жизненный цикл, IO, стримы, устройство изнутри, тесты и отладка | 14 |
| Сети и протоколы | TCP и UDP, фрейминг, свой HTTP/1.1 сервер и клиент, WebSocket, protobuf, HTTP/2, tonic, TLS и mTLS | 17 |
| Микросервисы и архитектура | слои и конфиг, DTO и ошибки API, авторизация, шлюз, NATS и JetStream, событийные паттерны, realtime, фоновые задачи, файлы, наблюдаемость, нагрузка и профилирование, устойчивость, хайлоад, безопасность, деплой | 20 |
| Базы данных | SQL от SELECT до оконных функций, моделирование, транзакции, sqlx, индексы, миграции, эксплуатация PostgreSQL, CQL и ScyllaDB, свой RESP клиент, типы и паттерны Redis, всё вместе | 26 |

Всего 122 главы: около 1360 задач на код, 570 вопросов, 164 проекта и 63 вехи.

Задачи бывают нескольких видов:

- **задача**: один файл, который нужно починить или дописать;
- **вопрос**: выбор вариантов или короткий ответ, проверяется сразу;
- **проект**: целый Cargo воркспейс с ТЗ в `README.md` и приёмочными тестами;
- **квиз и экзамен**: проекты в конце глав, на экзаменах без подсказок;
- **веха**: следующий шаг сквозного проекта.

### Сквозной проект: мини-соцсеть с нуля

Через весь курс проходит один проект. Вехи стоят прямо в главах, и каждая достраивает твой
код в папке `backend/` той темой, которую ты только что прошёл. Начинается всё с пользователей
и постов в памяти, а заканчивается набором сервисов:

- свои TCP, HTTP и WebSocket движки на голом tokio, без готовых фреймворков;
- шлюз, который по WebSocket и HTTP ходит в микросервисы по gRPC с mTLS;
- сервисы пользователей, постов, чатов и авторизации, события через NATS и JetStream;
- PostgreSQL с миграциями, outbox и поиском, чаты и ленты в ScyllaDB, кэш, очереди и лимиты в Redis;
- аккуратная остановка, наблюдаемость, нагрузочные тесты и деплой.

Вехи проверяются не только тестами: правила архитектуры следят за слоями, зависимостями и структурой
проекта. Если застрял на вехе, `rustlings journey baseline <веха>` подставит эталон предыдущей вехи,
а твоя версия уйдёт в бэкап.

### Язык

Интерфейс есть на русском и английском. Тексты задач написаны на русском, раздел «Основы Rust»
есть на обоих языках.

## Для авторов

Весь контент лежит в `exercises/` и `solutions/` и встраивается в бинарник при сборке,
поэтому после правок нужна пересборка. Проверить контент можно в корне клона:

```bash
rustlings dev check --lint
```

Запустить курс с контентом из папки, а не из бинарника:

```bash
RUSTLINGS_CONTENT_DIR=/path/to/rustlings-plus rustlings init
```

Тесты и линты самого CLI:

```bash
cargo test --workspace && cargo clippy -- --deny warnings
```

## English

Rustlings Plus is a Rust course of small exercises in your terminal, from the language basics
to your own HTTP and WebSocket engines on tokio, gRPC microservices, NATS, PostgreSQL, ScyllaDB
and Redis, with a mini social network you build from scratch along the way.

```bash
cargo install --git https://github.com/aianov/rustlings-plus --locked rustlings
```

```bash
rustlings init --lang en && cd rustlings && rustlings
```

Add `--force` to the install command if you already have the original Rustlings installed.
The interface is available in English and Russian. The exercise texts are written in Russian,
the "Rust basics" track is available in both languages.
