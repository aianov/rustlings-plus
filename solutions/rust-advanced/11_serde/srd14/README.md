# srd14

Клиент-заглушка ходит за документами по путям и разбирает ответ в любой тип, который попросит вызывающий:
`client.get::<Post>("/post/1")`. Файл не собирается, и компилятор жалуется, что `body` не живёт достаточно
долго. Тело ответа действительно создаётся внутри метода и умирает на выходе из него. Если разобранный `T`
мог бы ссылаться на эту строку, он пережил бы её, а такого Rust не допустит. Так же устроен `get_all`.
