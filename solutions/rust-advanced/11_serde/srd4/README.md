# srd4

Четыре сообщения протокола, и у каждого свой облик на проводе. Тесты ниже показывают точный JSON для каждого.
Варианты по умолчанию serde пишет «внешним тегом»: `{"Вариант": данные}`, но так нужно не всем:
`Command` помечает себя ключом внутри объекта, `Frame` держит тег и данные в двух соседних ключах,
а `Target` вообще без тега: просто число или просто строка.
