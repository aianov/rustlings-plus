# srd8

В сессии два промежутка времени, и клиент хочет их по-разному. `idle` приходит и уходит целым числом
миллисекунд, а `timeout` человеческой строкой: `30s`, `5m`, `2h`. У `Duration` в serde нет ни того ни
другого вида. Атрибуты `with` на полях уже стоят, не хватает самих функций в модулях `ms` и `human`.
При записи `human` выбирает самую крупную единицу, на которую время делится нацело (3600 с это `1h`,
120 с это `2m`, 90 с это `90s`, ноль это `0s`). При чтении неверная строка даёт ошибку с её текстом.
