# Проект: свой derive без syn

Каждый раз, когда ты пишешь `#[derive(Serialize)]`, программа на Rust во время компиляции получает текст
твоей структуры и возвращает другой текст: готовую реализацию. Это процедурный макрос. Обычно для него берут
крейты `syn` и `quote`, но под ними нет ничего магического: на вход приходит `TokenStream`, на выход уходит
`TokenStream`. Ты напишешь маленький derive `Describe` на одном `std` (крейт `proc_macro`), без чужих зависимостей.

## Что должен делать derive

`#[derive(Describe)]` на `struct` или `enum` добавляет к типу ассоциированные константы и метод.

- Для структуры с именованными полями: `Тип::TYPE_NAME` (имя типа), `Тип::FIELDS` (`&'static [&'static str]` с
  именами полей в порядке объявления), `Тип::describe()` вида `Profile { id, login }`.
- Для кортежной структуры: `FIELDS` содержит `"0"`, `"1"`, ..., `describe()` даёт `Pair(0, 1)`.
- Для структуры без полей: `FIELDS` пустой, `describe()` даёт просто имя.
- Для enum: `TYPE_NAME`, `VARIANTS` (имена вариантов по порядку), `describe()` вида `Reaction = Like | Emoji | Custom`.
  Данные вариантов и значения (`A = 1`) не учитываются.
- Любые атрибуты, доккомментарии и видимость (`pub`, `pub(crate)`) на типе, полях и вариантах не мешают и
  не попадают в результат. Типы полей могут содержать запятые внутри угловых скобок (`HashMap<String, Vec<u8>>`)
  и стрелки (`fn(u8) -> u8`, `Box<dyn Fn(u32) -> u32 + Send>`).
- Generic-типов в этой версии нет, их разбирать не нужно. Для `union` и прочего выдай ошибку компиляции с
  понятным сообщением (`compile_error!`).

## Как устроен вход

`TokenStream` это плоский поток токенов-деревьев: слова (`Ident`), знаки (`Punct`), литералы и группы в скобках
(`Group` с разделителем и вложенным потоком). Атрибут `#[allow(x)]` приходит как знак `#` и группа в `[]`,
`pub(crate)` как слово `pub` и группа в `()`. Тело структуры это группа в `{}`, кортежной в `()`.
Угловые скобки группами не являются: `<` и `>` это обычные знаки, поэтому глубину вложенности внутри
`Vec<(u8, u8)>` придётся считать самому. Знак `>` после `-` это стрелка, а не закрывающая скобка.

Результат проще всего собрать строкой и разобрать обратно: `код.parse::<TokenStream>()`.

## Что нужно сделать

В `crates/describe-derive/src/lib.rs` объявлена точка входа `derive_describe`, тело пустое.

## Как проверить

```
cargo test --workspace
```

Приёмочные тесты лежат в `crates/describe-derive/tests/acceptance.rs`, их менять нельзя. Они подключают
твой derive к настоящим типам и проверяют результат.
