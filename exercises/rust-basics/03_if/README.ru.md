# Условия if

Здесь ты изучишь `if`: самый простой (но всё равно на удивление гибкий!) вид управления потоком выполнения.

## Кратко

`if` в Rust это выражение, у него есть значение. Поэтому его можно присваивать переменной или возвращать из функции:

```rust
let max = if a > b { a } else { b };
```

Скобки вокруг условия не нужны, а само условие обязано быть типа `bool`: числа и строки к булеву типу сами не приводятся. Все ветки должны давать значение одного типа, иначе компилятор откажет. Если ветка `else` не нужна, то `if` должен возвращать `()`.

Цепочки условий пишутся через `else if`. Когда веток много, обычно лучше подходит `match`, до него мы ещё дойдём.
