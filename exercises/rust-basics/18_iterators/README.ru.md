# Итераторы

В этом разделе ты узнаешь об итераторах.

## Кратко

Итератор отдаёт элементы по одному через метод `next()`, возвращающий `Some(элемент)`, а в
конце `None`. Итераторы ленивые: пока ты не «потребишь» результат, ничего не вычисляется.

```rust
let words = ["hello", "world"];

let upper: Vec<String> = words
    .iter()                       // создаём итератор
    .map(|w| w.to_uppercase())    // адаптер: лениво преобразует
    .collect();                   // потребитель: запускает цепочку

let total: u32 = (1..=4).sum();   // 10
let fact: u64 = (1..=5).product(); // 120
```

Адаптеры (`map`, `filter`, `enumerate`, `flat_map`) превращают один итератор в другой,
потребители (`collect`, `sum`, `count`, `fold`) запускают вычисление. `collect` умеет собирать
в разные типы: `Vec`, `String`, `HashMap`, а из итератора `Result<T, E>` можно получить
`Result<Vec<T>, E>`, остановившись на первой ошибке. Тип результата Rust определяет по
аннотации, поэтому её обычно нужно указать.
