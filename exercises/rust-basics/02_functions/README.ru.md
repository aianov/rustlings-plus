# Функции

Здесь ты научишься писать функции и увидишь, как компилятор Rust помогает отлаживать ошибки
даже в более сложном коде.

## Кратко

Функция объявляется через `fn`. Типы всех аргументов указываются обязательно, тип результата пишется после `->`:

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

В последней строке нет точки с запятой: это выражение, и его значение становится результатом функции. Добавишь `;` и получится инструкция, а функция вернёт `()` (пустой кортеж, примерно как `void`). Это самая частая ошибка новичков. Досрочно вернуть значение можно через `return`.

Если функция ничего не возвращает, `-> ...` не пишется. Вызов с неправильным числом аргументов компилятор не пропустит.
