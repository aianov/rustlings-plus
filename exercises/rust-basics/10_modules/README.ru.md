# Модули

В этом разделе мы познакомим тебя с модульной системой Rust.

## Кратко

Модуль задаёт пространство имён: `mod shop { ... }`. Всё внутри по умолчанию приватно, и снаружи видно только то, что помечено `pub`:

```rust
mod shop {
    pub fn open() {}
    fn secret() {}
}

shop::open();
```

Инструкция `use` подключает путь в область видимости (`use std::time::{SystemTime, UNIX_EPOCH};`), а `as` даёт новое имя: `use a::B as C;`. Если написать `pub use`, имя станет частью публичного интерфейса модуля. Так можно показывать наружу не ту структуру, что внутри.

Пути бывают абсолютными (`crate::shop::open`) и относительными (`self::`, `super::`).
