# Тесты

Мы немного нарушаем порядок книги, чтобы разобрать тесты: многие следующие упражнения
просят тебя сделать так, чтобы тесты проходили!

## Кратко

Тест это обычная функция с атрибутом `#[test]`, лежащая в модуле `#[cfg(test)]`. Запускается
командой `cargo test`. Тест проходит, если функция завершилась, и падает, если она запаниковала.

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn it_works() {
        assert!(is_even(4));
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic]
    fn it_panics() {
        divide(1, 0);
    }
}
```

`assert!` проверяет условие, `assert_eq!` и `assert_ne!` сравнивают два значения и при
расхождении печатают оба. Последним аргументом можно передать свой текст сообщения.
`#[should_panic]` ожидает панику. Тесты работают в отдельном модуле, поэтому нужен
`use super::*;`, чтобы видеть код выше.
