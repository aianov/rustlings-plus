# Переменные

В Rust переменные по умолчанию неизменяемы.
Если переменная неизменяема, то после привязки значения к имени изменить это значение нельзя.
Чтобы сделать переменную изменяемой, добавь `mut` перед её именем.

## Кратко

`let x = 5;` создаёт привязку. Без `mut` присвоить `x` другое значение не выйдет, компилятор остановит. С `mut` можно:

```rust
let mut count = 0;
count += 1;
```

Затенение (shadowing) это повторный `let` с тем же именем. Оно создаёт новую переменную, поэтому тип может поменяться:

```rust
let input = "42";
let input: i32 = input.parse().unwrap();
```

Константы объявляются через `const`, всегда неизменяемы, и тип у них указывается обязательно: `const MAX: u32 = 100;`. Значение константы должно быть известно на этапе компиляции.

Переменную можно объявить без значения (`let x: i32;`), но читать её можно только после инициализации.
