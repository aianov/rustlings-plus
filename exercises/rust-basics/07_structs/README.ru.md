# Структуры

В Rust есть три вида структур: классическая структура как в C, кортежная структура и unit-структура.

## Кратко

Обычная структура хранит именованные поля. Кортежная обращается к полям по номеру, unit-структура вообще без полей:

```rust
struct Color { red: u8, green: u8, blue: u8 }
struct Point(i32, i32);
struct Marker;

let c = Color { red: 0, green: 255, blue: 0 };
let p = Point(1, 2);
println!("{} {}", c.green, p.0);
```

Синтаксис обновления `Color { red: 10, ..c }` берёт остальные поля из другого экземпляра. Методы и ассоциированные функции живут в блоке `impl`. У метода первым параметром идёт `self`, `&self` или `&mut self`, а у ассоциированной функции (например, конструктора `new`) такого параметра нет, и вызывается она как `Type::new()`.

Чтобы структуру можно было вывести через `{:?}`, добавь `#[derive(Debug)]`.
