# Строки

В Rust два строковых типа: срез строки (`&str`) и владеющая строка (`String`).
Мы не будем диктовать, когда какой использовать, но покажем, как их
отличать, создавать и применять.

## Кратко

`&str` это ссылка на строковые данные, которыми владеет кто-то другой. Строковый литерал в коде и есть `&str`. `String` владеет своим буфером в куче и может расти:

```rust
let s: &str = "привет";
let mut owned: String = s.to_string(); // или String::from(s)
owned.push_str(", мир");
let slice: &str = &owned; // String приводится к &str
```

В функцию обычно лучше принимать `&str`: она примет и литерал, и `&String`. Возвращать `String` нужно, когда строка создаётся внутри функции. Склеивать удобно макросом `format!`, а обрезать, заменять и менять регистр помогут методы `trim`, `replace`, `to_lowercase`.

Строки в Rust хранятся в UTF-8, поэтому индексы в срезе `&s[0..1]` считаются в байтах, а не в символах. Для символов используй `s.chars()`.
