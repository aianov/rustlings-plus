# Перечисления

Rust позволяет определять типы, называемые «перечислениями» (enum), которые перечисляют возможные значения.
Перечисления есть во многих языках, но возможности у них разные. Перечисления Rust больше всего похожи на алгебраические типы данных в функциональных языках, таких как F#, OCaml и Haskell.
Вместе с перечислениями полезно сопоставление с образцом (pattern matching) в Rust: с его помощью легко выполнять разный код для разных значений перечисления.

## Кратко

Вариант enum может быть пустым, кортежным или с именованными полями, и в каждом можно хранить свои данные:

```rust
enum Message {
    Quit,
    Echo(String),
    Resize { width: u64, height: u64 },
}

fn handle(m: Message) {
    match m {
        Message::Quit => println!("пока"),
        Message::Echo(s) => println!("{s}"),
        Message::Resize { width, height } => println!("{width}x{height}"),
    }
}
```

`match` обязан покрыть все варианты, иначе код не скомпилируется: так компилятор помогает не забыть новый случай. Для «всех остальных» есть шаблон `_`. Самые известные enum стандартной библиотеки это `Option<T>` и `Result<T, E>`.
