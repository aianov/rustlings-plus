# Clippy

Clippy это набор линтов, которые анализируют твой код, чтобы ты мог ловить типичные ошибки
и улучшать свой Rust-код.

Если ты ставил Rustlings установочным скриптом, Clippy уже установлен.
Если нет, поставь вручную: `rustup component add clippy`.

## Кратко

Запускается как `cargo clippy`. Он компилирует проект и сверх обычных предупреждений находит
неидиоматичный или подозрительный код: приближённые значения вместо `std::f32::consts::PI`,
цикл `for` по `Option`, `unwrap` сразу после проверки на `None`, ручной обмен значений.
К каждому замечанию Clippy пишет совет, как исправить.

```rust
// Clippy: используй `if let` вместо цикла по Option
for x in option { res += x; }
// лучше
if let Some(x) = option { res += x; }
```

Чтобы превратить предупреждения в ошибки, запусти `cargo clippy -- -D warnings`. Отдельное
срабатывание можно отключить атрибутом `#[allow(clippy::имя_линта)]`, но сначала подумай,
не прав ли Clippy.
