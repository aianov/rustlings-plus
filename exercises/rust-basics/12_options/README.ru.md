# Option

Тип `Option` представляет необязательное значение: каждый `Option` это либо `Some` с
значением внутри, либо `None` без него. `Option` очень часто встречается в Rust-коде,
потому что подходит для многого:

- начальные значения;
- возвращаемые значения функций, определённых не на всём множестве входов (частичные функции);
- возврат простой ошибки, когда при ошибке возвращается `None`;
- необязательные поля структур;
- поля структур, которые можно одолжить или «забрать»;
- необязательные аргументы функций;
- обнуляемые указатели;
- выход из трудных ситуаций при подмене значений.

## Кратко

В Rust нет `null`. Если значения может не быть, это записывается в типе: `Option<T>`.
Компилятор не даст использовать такое значение, пока ты не обработаешь оба случая.

```rust
let name: Option<&str> = Some("Ferris");

match name {
    Some(n) => println!("Привет, {n}"),
    None => println!("Привет, незнакомец"),
}

if let Some(n) = name {
    println!("{n}");
}
```

`unwrap` достаёт значение, но паникует на `None`, поэтому в настоящем коде лучше
`unwrap_or`, `?` или `match`. `while let Some(x) = stack.pop()` крутит цикл, пока
значения не кончатся. Если нужно посмотреть на содержимое, не забирая его, используй
`ref` в шаблоне или сопоставляй ссылку `&Option`, иначе значение переместится.
