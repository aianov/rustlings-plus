# Преобразования типов

В Rust множество способов превратить значение одного типа в другой.

Простейший из них это выражение приведения типа. Оно записывается бинарным оператором `as`.
Например, `println!("{}", 1 + 1.0);` не скомпилируется, потому что `1` целое, а `1.0` число
с плавающей точкой. Зато `println!("{}", 1 as f32 + 1.0)` скомпилируется. Это покрывает
упражнение [`conversions1`](conversions1.rs).

Ещё Rust предлагает трейты, которые упрощают преобразования после реализации. Они лежат в
модуле [`convert`](https://doc.rust-lang.org/std/convert/index.html).
Вот эти трейты:

- `From` и `Into`, разобраны в [`conversions2`](conversions2.rs)
- `TryFrom` и `TryInto`, разобраны в [`conversions4`](conversions4.rs)
- `AsRef` и `AsMut`, разобраны в [`conversions5`](conversions5.rs)

Кроме того, модуль `std::str` содержит трейт [`FromStr`](https://doc.rust-lang.org/std/str/trait.FromStr.html),
который помогает превращать строки в нужные типы методом `parse`. Если он правильно реализован
для типа `Person`, то `let p: Person = "Mark,20".parse().unwrap()` и скомпилируется, и выполнится
без паники.

Это основные способы ***в стандартной библиотеке*** превратить данные в нужный тип.

## Кратко

- `as` это грубое приведение между числовыми типами. Оно может обрезать значение
  (`300_i32 as u8 == 44`), поэтому для проверяемых преобразований лучше `TryFrom`.
- `From<A> for B` описывает безотказное преобразование; `Into` получается бесплатно:
  `let f: Fahrenheit = Celsius(20.0).into();`
- `TryFrom` / `TryInto` возвращают `Result`, когда преобразование может не удаться
  (например, `u8::try_from(300)`).
- `FromStr` задаёт разбор из строки, после него работает `"..".parse::<T>()`.
- `AsRef<T>` и `AsMut<T>` позволяют принимать «всё, из чего дёшево получить ссылку на `T`»:
  `fn len<S: AsRef<str>>(s: S) -> usize { s.as_ref().len() }` примет и `&str`, и `String`.
