# Умные указатели

В Rust умные указатели это переменные, которые хранят адрес в памяти и ссылаются на другие
данные, но при этом несут дополнительные метаданные и возможности. Умные указатели часто
владеют данными, на которые указывают, а обычные ссылки данные только заимствуют.

## Кратко

- `Box<T>` кладёт значение в кучу. Нужен для рекурсивных типов (например, списка, в котором
  элемент содержит следующий такой же) и для `Box<dyn Trait>`.
- `Rc<T>` даёт нескольких владельцев в одном потоке. `Rc::clone(&a)` не копирует данные,
  а увеличивает счётчик; значение освобождается, когда счётчик доходит до нуля.
- `Arc<T>` то же самое, но потокобезопасное. Для изменения данных в нескольких потоках его
  комбинируют с `Mutex`: `Arc<Mutex<T>>`.
- `Cow<T>` («клонировать при записи») держит заимствованные данные и копирует их, только
  если их нужно изменить.

```rust
use std::rc::Rc;

enum List {
    Cons(i32, Box<List>),
    Nil,
}

let a = Rc::new(5);
let b = Rc::clone(&a);
println!("{}", Rc::strong_count(&a)); // 2
```
