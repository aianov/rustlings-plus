# Асинхронность

Асинхронное программирование это модель, в которой задачи передаются рантайму, и он выполняет
их конкурентно. Она особенно эффективна, когда программа делает много независимых операций
ввода-вывода, например в веб-серверах.

Rust предоставляет в языке нужные примитивы для асинхронного программирования.
Но в стандартной библиотеке Rust рантайма нет.
В этих упражнениях мы используем самый распространённый рантайм `tokio`.

## Кратко

`async fn` возвращает не результат, а футуру (future): описание работы, которое само ничего не
делает. Выполняет её рантайм, а получить результат можно, написав `.await`. Пока одна задача ждёт
ввод-вывод, рантайм выполняет другие, поэтому тысячи задач помещаются в несколько потоков.

```rust
#[tokio::main]
async fn main() {
    let task = tokio::spawn(double(21));
    println!("{}", task.await.unwrap()); // 42
}

async fn double(n: u32) -> u32 {
    n * 2
}
```

`tokio::spawn` запускает задачу в фоне и возвращает `JoinHandle`, у которого `.await` даёт
`Result` (задача могла паниковать). Внутри `async` нельзя блокировать поток обычными
`std::thread::sleep` или `std::fs`, используй их версии из `tokio`.
