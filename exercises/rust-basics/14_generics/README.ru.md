# Обобщённые типы

Обобщения (generics) позволяют распространить типы и функциональность на более широкие случаи.
Это сильно сокращает дублирование кода, но синтаксис может быть непростым: нужно аккуратно
указывать, для каких именно типов обобщённый тип считается допустимым.
Самое простое и частое применение обобщений это параметры типов.

## Кратко

Вместо того чтобы писать `fn first_i32(v: &[i32])` и `fn first_str(v: &[&str])`, пишешь одну
функцию с параметром типа `T`. Компилятор сам подставит нужный тип и сгенерирует код под каждый.

```rust
struct Wrapper<T> {
    value: T,
}

impl<T> Wrapper<T> {
    fn new(value: T) -> Self {
        Wrapper { value }
    }
}

let a = Wrapper::new(42);
let b = Wrapper::new("hi");
```

Если внутри нужно что-то делать со значением (печатать, сравнивать), добавь ограничение:
`T: Display`. Если компилятор не может сам вывести `T`, подскажи аннотацией:
`let v: Vec<i16> = Vec::new();`. Накладных расходов в рантайме нет: обобщённый код
мономорфизируется, то есть превращается в конкретные версии на этапе компиляции.
