# Векторы

Векторы это одна из самых используемых структур данных Rust. В других языках программирования
их назвали бы просто массивами, но Rust работает на несколько более низком уровне: массив
в Rust хранится на стеке (то есть не может расти или уменьшаться, а его размер должен быть
известен на этапе компиляции), а вектор хранится в куче (где этих ограничений нет).

В книге векторы встречаются в одной из поздних глав, но мы решили, что они достаточно полезны,
чтобы заняться ими пораньше. Про другую полезную структуру данных, хеш-таблицы, поговорим позже.

## Кратко

`Vec<T>` это растущий список значений одного типа. Создаётся через `Vec::new()` или макрос `vec![]`, дополняется методом `push`:

```rust
let mut v = vec![1, 2, 3];
v.push(4);
let doubled: Vec<i32> = v.iter().map(|x| x * 2).collect();
```

Обращаться по индексу можно (`v[0]`), но при выходе за границы программа паникует. Безопаснее `v.get(0)`, он возвращает `Option`. Обходить вектор удобно циклом `for x in &v`, а менять элементы на месте цикл `for x in &mut v`.
