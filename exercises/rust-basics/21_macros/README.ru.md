# Макросы

Система макросов Rust очень мощная, но осмыслить её непросто. Мы не будем учить тебя писать
полноценные макросы. Вместо этого покажем, как их использовать и создавать.

Если хочешь больше узнать о написании своих макросов, у проекта
[macrokata](https://github.com/tfpk/macrokata) формат упражнений похож на Rustlings, но
целиком посвящён тому, как писать макросы.

## Кратко

Макрос вызывается с `!` (`println!`, `vec!`) и раскрывается в код во время компиляции. Простые
макросы пишут через `macro_rules!`: это набор веток «образец => код», разделённых `;`.

```rust
macro_rules! square {
    ($x:expr) => {
        $x * $x
    };
}

fn main() {
    println!("{}", square!(7));
}
```

Макрос должен быть определён выше места, где он используется. Чтобы использовать макрос
из вложенного модуля снаружи, ставят `#[macro_use]` на модуль (или `#[macro_export]` на
сам макрос). `$x:expr` значит «подставь любое выражение», есть и другие виды фрагментов:
`ident`, `ty`, `tt`.
