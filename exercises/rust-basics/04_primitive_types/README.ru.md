# Примитивные типы

В Rust есть несколько базовых типов, которые реализованы прямо в компиляторе.
В этом разделе пройдёмся по самым важным.

## Кратко

Скалярные типы: целые (`i32`, `u8`, `usize` и другие), числа с плавающей точкой (`f64`), `bool` и `char`. Символ `char` пишется в одинарных кавычках и хранит один символ Unicode, в том числе эмодзи.

Составные типы собираются из нескольких значений. Массив `[T; N]` имеет фиксированную длину, кортеж может хранить значения разных типов:

```rust
let a = [0; 100];
let cat = ("Мурзик", 3.5);
let (name, age) = cat;
let age_again = cat.1;
```

Срез `&a[1..4]` это ссылка на кусок массива (или вектора). Верхняя граница не входит в диапазон, а `1..=3` включает её.
