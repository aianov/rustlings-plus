# Трейты

Трейт это набор методов.

Типы данных могут реализовывать трейты: для этого методы, составляющие трейт, определяются
для типа. Например, тип `String` реализует трейт `From<&str>`, поэтому можно писать
`String::from("hello")`.

В этом смысле трейты похожи на интерфейсы Java и абстрактные классы C++.

Ещё несколько распространённых трейтов Rust:

- `Clone` (метод `clone`)
- `Display` (форматированный вывод через `{}`)
- `Debug` (форматированный вывод через `{:?}`)

Трейты описывают общее поведение разных типов, поэтому они незаменимы при работе с обобщениями.

## Кратко

Трейт объявляет, что тип умеет делать. У методов может быть реализация по умолчанию.

```rust
trait Greet {
    fn name(&self) -> String;
    fn hello(&self) -> String {
        format!("Привет, {}", self.name())
    }
}

struct Dog;
impl Greet for Dog {
    fn name(&self) -> String { "Рекс".to_string() }
}
```

В параметрах функции трейт задаётся как `impl Greet` или как ограничение `T: Greet`;
несколько трейтов склеиваются через `+`: `T: Greet + Clone`. Так можно принимать любые
типы с нужным поведением, не зная конкретного типа. Реализовывать можно свой трейт для
чужого типа и чужой трейт для своего типа, но не чужой для чужого (правило сироты).
