# Проект: журнал доступа без копирования

Сервер за сутки пишет миллионы строк вида `203.0.113.7 GET /feed?page=2 200 "Mozilla/5.0"`. Нужна
библиотека, которая читает такой журнал и отвечает на вопросы «кто получил 500» и «какие запросы шли на
`/feed`», не копируя каждую строку в отдельный `String`. Библиотека `access-log` владеет одним большим
буфером, а записи это временные «окна» в него.

## Формат строки

```
<ip> <method> <target> <status> "<agent>"
```

Поля разделены пробелами (один или несколько). `status` число `u16`. `agent` в двойных кавычках; внутри
кавычек `\"` значит кавычку, `\\` значит одну обратную косую, остальное берётся как есть. После
закрывающей кавычки допустимы только пробелы. Пустые строки (и строки из одних пробелов) пропускаются, `\r\n` в конце допустим.

## Что нужно сделать

В `src/lib.rs` объявлены типы и сигнатуры, тела пустые.

1. `AccessLog::new(buffer)` забирает буфер и проверяет все строки. Первая плохая строка даёт
   `LogError { line, reason }`, где `line` номер строки с единицы (пустые строки считаются) и `reason` один из
   `"missing field"` (нет одного из первых четырёх полей: ip, method, target, status), `"bad status"` (не число),
   `"bad agent"` (первые четыре поля есть, а агента нет, он без кавычек, не закрыт или после закрывающей кавычки мусор). Хранить нужно диапазоны строк в буфере, а не копии строк.
2. `len`, `is_empty` (число записей), `raw` (буфер целиком), `get(i)` (запись по номеру).
3. `Entry<'a>` содержит куски буфера: `ip`, `method`, `target` это `&'a str`, `agent` это `Cow<'a, str>`:
   заимствованный, если внутри нет обратной косой, и владеющий (с раскодированными `\"` и `\\`), если есть.
4. `Entry::path()` (цель до `?`) и `Entry::query()` (после `?`) возвращают куски с тем же `'a`, что и запись:
   их можно оставить, когда сама `Entry` уже выброшена.
5. `entries()` итератор по всем записям в порядке файла, `with_status(min, max)` только записи со статусом
   в диапазоне (включительно). Оба ленивые.

## Критерии приёмки

- разбор формата, экранирование, номера строк в ошибках;
- поля это куски буфера (проверяется по адресам), агент без экранирования это `Cow::Borrowed`;
- журнал можно переместить, записи после этого по-прежнему указывают в его буфер;
- `AccessLog::new` на 20 000 строк делает не больше шести аллокаций, обход `entries()` и первая запись
  из `with_status` не делают ни одной.

## Как проверить

```
cargo test
cargo clippy --all-targets -- -D warnings
```

## Подсказки по теории

Структура не может хранить `&str` на собственное поле, поэтому хранят `Vec<Range<usize>>`, а `&str`
вырезают на лету. Запись отдаёт куски с временем жизни `'a`, а не `&self`: тогда они живут столько же, сколько
журнал. Для повторного разбора строки при `get` и обходе пригодится приватная функция
`parse_line(&str) -> Result<Entry<'_>, &'static str>`. Подсчитать места под диапазоны можно заранее по числу
переводов строки.
