# srd1

Пользователи ленты должны путешествовать по сети, а по сети ходят байты в формате JSON. Сейчас `User` это
обычная структура, и превратить её в текст нечем. Нужны четыре функции: в строку, в байты, из строки и из байтов.
Порядок полей в JSON совпадает с порядком в структуре. Сериализация такой структуры не может
провалиться, а вот разбор чужого текста может, и эту ошибку надо вернуть, а не паниковать.
