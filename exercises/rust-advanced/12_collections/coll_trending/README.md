# Проект: хранилище постов с индексами

Соцсеть растёт, и «обойти все посты и отфильтровать» перестало годиться. Нужно хранилище в памяти, которое
отвечает на четыре вопроса без полного обхода: что написал этот автор (страницами, от новых к старым), какие
посты с этим хештегом, какие посты сейчас в трендах, и почему удалённый пост всё ещё где-то виден (не должен).
Крейт `post-store` это ядро хранилища: только `std`, никакой сети.

## Что нужно сделать

В `crates/post-store/src/lib.rs` объявлены типы и сигнатуры, тела пустые. Структуру `Store` и её поля можно менять,
открытый API менять нельзя.

1. `add_post(author, ts, text)` создаёт пост, id выдаются подряд с единицы. Хештеги берутся из текста: слова,
   начинающиеся с `#`, в нижнем регистре (`hashtags` уже написана). `get(id)` отдаёт пост.
2. `author_page(author, cursor, n)`: страница постов автора от новых к старым. Порядок по `(время, id)`: при одинаковом
   времени больший id новее. `cursor` это ключ `(время, id)` последнего поста прошлой страницы (посты до него, сам он
   не включается). `Page.next` это ключ последнего поста страницы, если за ним есть ещё посты, иначе `None`. Лишнего
   пустого запроса быть не должно.
3. `with_tag(tag)` отдаёт id постов тега по возрастанию. `tags_known()` считает теги, у которых есть посты.
4. `edit(id, text)` меняет текст и теги (старые теги поста убираются, новые добавляются). `delete(id)` убирает пост
   отовсюду: из страниц автора, из тегов, из лайков. Пустые записи индексов (автор без постов, тег без постов)
   исчезают. `false`, если поста нет.
5. `like(post, user, ts)`: один пользователь лайкает пост один раз. `Ok(true)` новый лайк, `Ok(false)` повтор,
   `Err(StoreError::NoSuchPost(id))` если поста нет (в том числе удалённого). `like_count(post)` считает все лайки.
6. `trending(now, window, n)`: до `n` постов с наибольшим числом лайков за окно. В окно входят лайки со временем
   `t`, где `now - window < t <= now` (вычитание не уходит ниже нуля). Результат: пары `(id поста, лайки в окне)`
   по убыванию лайков, при равенстве меньший id раньше. Посты без лайков в окне в тренды не попадают. Набор
   кандидатов не должен расти с числом постов: держи не больше `n` элементов в куче.

## Как проверить

```
cargo test --workspace
```

Приёмочные тесты лежат в `crates/post-store/tests/acceptance.rs`, их менять нельзя.
