# cargo make в воркспейсе

Нужен установленный `cargo-make` (`cargo install cargo-make`): приёмка запускает его всерьёз.

В воркспейсе два крейта и `Makefile.toml` с задачами `fmt`, `lint`, `test` и `check` (последняя
собирает остальные). Выглядит правильно, но `cargo make check` ведёт себя странно: выводит логи
по очереди для каждого крейта, а настоящих проверок не делает. Что-то подмешивается, хотя автор
такого не писал.

## Что должно получиться

1. `cargo make check` из корня выполняет ровно три команды: форматирование, clippy, тесты. Порядок
   именно такой. Каждая команда один раз на весь воркспейс, а не по разу на крейт.
2. `cargo make fmt`, `cargo make lint`, `cargo make test` тоже выполняют по одной команде.
3. Проверки остаются строгими: плохое форматирование или предупреждение clippy в любом крейте
   роняет `check`.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты читают строки `Execute Command` из вывода cargo-make и считают их.
