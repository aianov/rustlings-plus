# Makefile для повседневных команд

В проекте `greeter` команды вроде `cargo clippy --all-targets -- -D warnings` каждый печатает по памяти.
Кто-то завёл `Makefile`, чтобы набирать `make lint`. Но файл пока не работает: `make build` отвечает
про отсутствующий разделитель, `make test` сообщает, что делать нечего, хотя тесты есть и их никто не запускал.

## Что должно получиться

1. Цели: `build`, `test`, `fmt`, `lint`, `check`.
2. `test` перед запуском тестов собирает проект, то есть зависит от `build`.
3. `check` выполняет `fmt`, `lint`, `test` именно в таком порядке.
4. `make` без аргументов делает то же, что `make check`.
5. Цели работают всегда, даже если в папке лежит файл или каталог с таким же именем. В проекте уже
   есть папки `build/` и `test/`, и они не случайность.
6. `fmt` падает на неотформатированном коде, `lint` падает на предупреждениях clippy.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты запускают настоящий `make`, в том числе с флагом `-n` (показать команды, не выполняя), и
подкладывают в копию проекта плохо отформатированный код и файлы, мешающие целям.
