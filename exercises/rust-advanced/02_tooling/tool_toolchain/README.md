# Одинаковое окружение у всех

Три разработчика и CI форматируют код по-разному, собирают разными компиляторами и спорят в ревью
о ширине строки. На ноутбуке всё зелёное, в CI красное: у коллеги другая версия clippy со свежими
правилами. Обещанного `make check` тоже не хватает: он тихо перепишет Cargo.lock, если тот
устарел.

## Что должно получиться

1. `rust-toolchain.toml` закрепляет точную версию компилятора 1.88.0 (не `stable`) и
   подтягивает компоненты `rustfmt` и `clippy`. Профиль установки минимальный.
2. `rustfmt.toml`: максимальная ширина строки 80, поля структур записываются сокращённо
   (`use_field_init_shorthand`). Код проекта отформатирован по этим правилам.
3. `clippy.toml`: вызов `std::process::exit` запрещён (программа возвращает `ExitCode`), функции
   с пятью и более аргументами считаются слишком большими.
4. Цель `make check` ходит с `--locked`: устаревший `Cargo.lock` должен ронять проверку, а не
   переписываться молча.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты читают файлы настроек и проверяют их действие: подкладывают в копию проекта слишком длинную
строку, вызов `exit`, функцию с пятью аргументами и удаляют `Cargo.lock`.
