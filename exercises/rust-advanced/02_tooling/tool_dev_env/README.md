# Сборка окружения разработчика

Нужен установленный `cargo-make` (`cargo install cargo-make`): приёмка запускает его всерьёз.

Новый человек в команде клонирует репозиторий и тратит день на то, чтобы всё запустилось: какой
компилятор, как форматировать, чем гонять проверки, как поднять сервисы. У нас в репозитории три
сервиса и ядро, и ни одного файла окружения. Соберём их все.

## Что должно получиться

В корне репозитория:

```
Makefile              короткие команды для всех
Makefile.toml         то же и больше для cargo make
.env                  уже есть, локальные настройки
.env.example          образец для новых людей, те же ключи
.cargo/config.toml    алиас cargo xtask
rust-toolchain.toml   закреплённая версия компилятора
rustfmt.toml          правила форматирования
clippy.toml           правила clippy
tools/xtask/          крейт со скриптами на Rust
```

## Требования

1. `make run SERVICE=auth` запускает указанный сервис, `SERVICE=worker make run` делает то же через
   окружение, без указания запускается `api`. `make check` выполняет `fmt`, `lint`, `test` по порядку.
   Цели `run`, `build`, `test`, `fmt`, `lint`, `check` работают, даже если рядом лежит файл с таким именем.
2. `cargo make check` делает ровно три шага (форматирование, clippy, тесты), без лишнего `cargo check`.
   Задача `fmt` только проверяет, ничего не правит.
3. `cargo make run-all` собирает проект один раз и запускает три сервиса одновременно. Пауза сервисов
   (`SERVICE_SLEEP_MS`) приходит из `.env`, но переменная из оболочки сильнее файла.
4. `cargo xtask check` и `cargo xtask new-service <имя>` ведут себя так же, как в задаче про xtask:
   проверка всего, создание заготовки в `services/<имя>` по правилам имён.
5. `rust-toolchain.toml` закрепляет точную версию компилятора и компоненты `rustfmt`, `clippy`.
   `rustfmt.toml` задаёт ширину строки, `clippy.toml` запрещает хотя бы один метод. Код проекта
   проходит `cargo fmt --check` по вашему `rustfmt.toml`.
6. `.env.example` содержит те же ключи, что и `.env`.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Дополнительно запусти `cargo make check`, `cargo xtask check` и `make check` руками: все три должны
быть зелёными.
