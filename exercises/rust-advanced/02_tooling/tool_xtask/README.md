# xtask: скрипты на Rust

Правила проекта (проверки, создание заготовки нового сервиса) сейчас передаются устно и копипастой
из чата. Хочется, чтобы это были команды `cargo xtask check` и `cargo xtask new-service billing`,
написанные на Rust, лежащие в репозитории и проверяемые тестами. В воркспейсе уже есть крейт
`tools/xtask`, но он ничего не умеет, и самой команды `cargo xtask` тоже нет.

## Что должно получиться

1. `cargo xtask` работает из корня воркспейса без лишнего шума сборки.
2. `cargo xtask check` из корня выполняет проверку формата, clippy с запретом предупреждений и тесты
   всего воркспейса. Падает, если падает любая из проверок.
3. `cargo xtask new-service <имя>` создаёт `services/<имя>/` с `Cargo.toml` и `src/main.rs`,
   где программа печатает `<имя> started`. Новый сервис сразу собирается (членов подхватывает маска),
   в `Cargo.toml` корня ничего дописывать не нужно.
4. Имя сервиса: маленькие латинские буквы, цифры и дефис, начинается с буквы. Всё остальное
   отвергается, и на диске ничего не появляется. Существующий сервис не перезаписывается.
5. Без аргументов и с неизвестной подкомандой команда печатает справку, где названы `check` и
   `new-service`, и завершается с ненулевым кодом.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты копируют проект, создают сервисы, ломают форматирование и clippy и смотрят, как отвечает xtask.
