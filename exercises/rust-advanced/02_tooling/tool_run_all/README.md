# Много сервисов одной командой

Нужен установленный `cargo-make` (`cargo install cargo-make`): приёмка запускает его всерьёз.

В воркспейсе три сервиса: `api`, `auth`, `worker`. Каждый стартует, живёт три секунды и выходит
(так мы имитируем долгую работу). Для каждого есть задача в `Makefile.toml`. `cargo make run-all`
должна поднимать все три, но сейчас делает это по очереди: пока один не закончился, второй не стартует.
Разработчики ждут девять секунд там, где хватило бы трёх.

## Что должно получиться

1. `cargo make run-all` запускает все три сервиса одновременно: время работы примерно как у одного.
2. Перед запуском проект собирается один раз (`cargo build --workspace`), чтобы три `cargo run`
   не дрались за сборку.
3. Отдельные задачи (`cargo make api` и так далее) продолжают работать.
4. Общая переменная `SERVICE_SLEEP_MS` остаётся в одном месте, в `[env]`.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты замеряют время `cargo make run-all`, проверяют порядок строк в выводе и считают команды сборки.
