# cargo make: задачи в Makefile.toml

Нужен установленный `cargo-make` (`cargo install cargo-make`): приёмка запускает его всерьёз.

В проекте `ledger` команды разработчика живут в головах: форматирование, clippy, тесты, запуск с
настройками из `.env`. Хочется набирать `cargo make check` и знать, что так делает и коллега, и CI.
В корне лежит пустой `Makefile.toml`.

## Что должно получиться

1. Задачи `fmt` (проверка форматирования без правок), `lint` (clippy, предупреждения считаются ошибками),
   `test`.
2. Задача `check` выполняет `fmt`, `lint`, `test` по порядку и больше ничего. В частности, никакого
   лишнего `cargo check`.
3. Задача `run` запускает программу. Переменные берутся из файла `.env`, но если та же переменная
   задана в оболочке (`LOG_LEVEL=debug cargo make run`), побеждает оболочка.
4. `.env.example` перечисляет те же переменные, что и `.env`. Сам `.env` в реальных проектах не
   коммитят, а здесь он лежит, чтобы можно было сразу запускать.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
cargo make check
```

Тесты запускают настоящий `cargo make` и читают строки `Execute Command` из его вывода, чтобы
увидеть, что и в каком порядке было выполнено.
