# Секция [lints]

Раньше правила для компилятора и clippy выставляли флагами (`-D warnings`) или атрибутами
`#![forbid(unsafe_code)]` в начале каждого крейта. Теперь их можно записать в `Cargo.toml` один раз
на пакет, и они сработают на все цели: библиотеку, бинарники, тесты, примеры.

В `slug-kit` договорились: никакого `unsafe` и никакого `.unwrap()`. Пока этого нет в манифесте,
в коде есть и то и другое.

## Что сделать

1. В `Cargo.toml` добавь:
   - `[lints.rust]` с `unsafe_code = "forbid"`;
   - `[lints.clippy]` с `unwrap_used = "deny"`.
   Заодно включи базовый набор clippy как предупреждения: запись
   `all = { level = "warn", priority = -1 }` (приоритет нужен, чтобы конкретные правила имели последнее слово).
2. Теперь приведи в порядок `src/lib.rs`. Функции возвращают `Option`:
   `first_byte(&str) -> Option<u8>` и `parse_port(&str) -> Option<u16>`.

## Приёмка

Тесты проверяют не текст манифеста, а поведение. Они копируют пакет во временную папку, дописывают
в `lib.rs` новый `.unwrap()` или `unsafe`, запускают `cargo clippy` и ждут отказа. А ещё clippy
должен спокойно проходить по настоящему коду.

```
cargo clippy --all-targets -- -D warnings
cargo test
```
