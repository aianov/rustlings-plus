# Библиотека и бинарники в одном пакете

В пакете `word-count` вся логика живёт в библиотеке (`src/lib.rs` и `src/stats.rs`), а
программы поверх неё должны быть тонкими: прочитать ввод, позвать библиотеку, напечатать.
Одна из программ ещё не написана, другой нет совсем.

## Что сделать

1. `src/main.rs`: читает весь stdin, считает слова функцией `analyze` из библиотеки и печатает
   `words: <число>`. Библиотека доступна по имени пакета с подчёркиванием: `word_count::...`.
2. Добавь второй бинарник `lines`: читает stdin и печатает `lines: <число>`. В `Cargo.toml`
   ничего менять не нужно, достаточно положить файл на нужное место (какое, написано в README главы).
3. Ни `src/main.rs`, ни второй бинарник не объявляют собственных `mod`.

## Приёмка

`tests/acceptance.rs` запускает оба бинарника со stdin и вызывает библиотеку напрямую. Ещё он читает
исходники бинарников и ругается на `mod`.

```
cargo test
echo "раз два три" | cargo run --bin word-count
echo "раз два три" | cargo run --bin lines
```
