# Модуль, подключённый дважды

Пакет `shelf` состоит из библиотеки и бинарника, и модуль `model` объявлен в обоих корнях:
`pub mod model;` в `src/lib.rs` и `mod model;` в `src/main.rs`. Cargo считает это двумя разными
крейтами, которые просто читают один файл. Тип `Book` получился в двух экземплярах, и компилятор
отказывается складывать их друг с другом. В сообщении об ошибке смотри на пути: у одного типа он
начинается с имени пакета, у другого нет.

## Что сделать

Почини `src/main.rs` так, чтобы бинарник пользовался типом из библиотеки. Файл `model.rs`
и `lib.rs` менять не нужно.

## Приёмка

```
cargo test
cargo run          # 2 books, 1016 pages
```

Тесты проверяют сводку и то, что в `main.rs` не осталось собственных `mod`.
