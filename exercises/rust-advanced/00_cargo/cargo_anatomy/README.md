# Пакет, крейт и цели

Игрушечный калькулятор `tiny-calc` лежит перед тобой: библиотека с функцией `eval`,
бинарник, который считает выражение из аргументов, второй бинарник для замеров и пример.
Код хороший, а `cargo test` падает. Виноват манифест.

## Что сделать

В `Cargo.toml`:

1. Включи edition 2024. Библиотека использует цепочку `if let ... && ...`, а она есть только в 2024.
2. Объяви `rust-version = "1.88"`, чтобы старый компилятор получил понятную ошибку, а не простыню.
3. Переименуй второй бинарник: файл `src/bin/bench.rs` должен собираться как `calc-bench`.
   Сделай это секцией `[[bin]]` с `name` и `path`. Файл не переименовывай.

## Приёмка

`tests/acceptance.rs` просит у cargo список целей пакета (`cargo metadata`) и проверяет, что cargo видит:
библиотеку `tiny_calc`, бинарники `tiny-calc` и `calc-bench`, пример `demo` и тест `acceptance`.
Потом запускает оба бинарника и пример. Тесты править нельзя: перед проверкой они восстанавливаются.

```
cargo test
cargo metadata --no-deps --format-version 1     # то, что видят тесты
```
