# Три вида зависимостей

В пакете `report-tool` три вспомогательных крейта, и каждый нужен в своё время:

| крейт     | где используется                       |
|-----------|----------------------------------------|
| `fmtkit`  | в коде библиотеки, то есть в программе |
| `testkit` | только в `#[cfg(test)]` и в тестах     |
| `stamp`   | только в `build.rs`                    |

Сейчас они разложены по секциям неправильно, и пакет не собирается.

## Что сделать

Разнеси зависимости по `[dependencies]`, `[dev-dependencies]` и `[build-dependencies]`.
Кода трогать не нужно. Править руками необязательно: `cargo add` и `cargo remove` умеют работать
с секциями и путями.

```
cargo add --dev testkit --path crates/testkit
cargo remove stamp
```

## Приёмка

Тесты спрашивают cargo, а не читают манифест глазами: `cargo tree --edges normal|build|dev` должен
показать ровно по одному крейту в каждом виде зависимостей. Ещё запускается бинарник и проверяется
его вывод.

```
cargo test
cargo tree --edges build --depth 1
```
