# Профили сборки

Профиль это набор настроек компилятора. Есть два встроенных: `dev` (для `cargo build` и `cargo test`)
и `release` (для `cargo build --release`). Менять их можно в `Cargo.toml`, не трогая код.

Пакет `profile-lab` считает контрольную сумму тяжёлым циклом в крейте `heavy`. В dev он медленный,
потому что оптимизаций почти нет, а в отладчике, наоборот, хочется видеть код как написан.

## Что сделать

В `Cargo.toml` добавь профили:

1. `[profile.dev]`: `opt-level = 1` (чуть быстрее, отладка ещё читается).
2. `[profile.dev.package.heavy]`: `opt-level = 3`. Один горячий крейт оптимизируем всегда, свой код
   оставляем отлаживаемым.
3. `[profile.release]`: `lto = true`, `codegen-units = 1`, `panic = "abort"`, а ещё
   `overflow-checks = true`: целочисленное переполнение в нашем проекте должно оставаться ошибкой и
   в готовой программе.

## Приёмка

Тесты собирают пакет с `-v` и читают, с какими флагами cargo запустил `rustc`, а ещё запускают
`probe` в release: `255 + 1` в `u8` обязано завершиться аварийно.

```
cargo build -v
cargo build --release -v
cargo run --release --bin probe -- 255
```
