# Проект: шина команд

Терминал нашей соцсети принимает команды: `post`, `like`, `follow`, `whoami`. Сейчас это огромный
`match` по имени, и каждая новая команда правит его. Хочется иначе: команды регистрируются по
имени, у каждой своя функция или замыкание, возвращать из неё можно что удобно (строку, пару «код и
текст», `Result`), а общие вещи (счётчик, текущий пользователь, уведомитель) лежат в контексте и
достаются по типу. Это та же схема, что стоит под веб-фреймворками, только маленькая.

## Что нужно сделать

Библиотека `command-bus`. В `src/lib.rs` типы `Response`, `IntoResponse`, `Notifier`, `Context` и
`Bus`. Заготовка собирается, но методы пустые.

1. `IntoResponse` для `Response` (как есть), `String` и `&'static str` (статус 200),
   `(u16, String)` (статус из пары) и `Result<T, E>` для любых `T` и `E`, которые сами `IntoResponse`.
   Для `Ok` берётся ответ значения. Для `Err` ответ ошибки, но если у него вышел статус 200, он
   заменяется на 500.
2. `Context`: типизированная карта. `insert` кладёт значение и возвращает прежнее значение того же типа,
   `get` и `get_mut` достают по типу. Значения разных типов не мешают друг другу. В карту можно класть
   `Arc<dyn Notifier>`: уведомитель это трейт-объект, выбранный при запуске.
3. `Bus::register(name, handler)`. Обработчик это `Fn(&mut Context, &str) -> R`, где `R: IntoResponse`,
   плюс границы, чтобы шину можно было делить между потоками. Метод возвращает `true`, если команда с таким
   именем уже была и её заменили. Обработчики разных типов хранятся в одной таблице: стирай тип.
4. `Bus::dispatch(name, ctx, args)` вызывает обработчик, превращает результат в `Response`. Неизвестная
   команда это статус 404 и тело `unknown command: <имя>`.
5. `Bus::names()` возвращает имена по алфавиту.
6. `Bus` и `Context` должны быть `Send + Sync`: шину кладут в `Arc`, а у каждого потока свой контекст.
7. `Bus::layer(слой)` добавляет проверку перед командами (например, права). Слой это трейт `Layer` с
   методом `before(команда, аргументы) -> Option<Response>`: `Some` значит «остановить, вот ответ».
   Слои опрашиваются в порядке добавления и до поиска обработчика (неизвестную команду они тоже видят);
   первый отказ побеждает, остальные слои и обработчик не запускаются.

## Подсказки по теории

Таблица хранит `Box<dyn ErasedHandler>` (свой внутренний трейт с одним методом, возвращающим уже
`Response`). Мост от обычного замыкания это структура-обёртка, реализующая трейт для любого подходящего `F`.
Тип результата `R` обёртке в структуре не нужен: в реализации трейта его определяет граница
`F: Fn(&mut Context, &str) -> R`. Контекст хранит `Box<dyn Any + Send + Sync>` по ключу `TypeId`; чтобы
вернуть значение прежнего типа из `insert`, понадобится `downcast` у ящика.
