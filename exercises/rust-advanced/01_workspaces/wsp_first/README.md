# Первый воркспейс

В папке лежат два готовых крейта: библиотека `geometry` и программа `shapes-cli`, которая должна ею
пользоваться. Каждый крейт рабочий сам по себе, но вместе они не собираются: корня, который объединил
бы их, нет, а программа не знает, где искать библиотеку.

## Что должно получиться

```
.
  Cargo.toml                   новый корневой манифест
  src/crates/geometry/         библиотека
  src/crates/shapes-cli/       программа
  acceptance/                  приёмка (не трогай)
```

1. Крейты собираются вместе: `cargo build --workspace` из корня и `cargo run -p shapes-cli -- 3 4` печатают
   `area=12 perimeter=14`.
2. Корень не пакет, он только перечисляет крейты.
3. Новый крейт, добавленный в `src/crates/`, попадает в сборку без правок корня.
4. Cargo не выдаёт предупреждений про resolver.
5. Cargo.lock и target существуют в единственном экземпляре, в корне; ни один крейт не заводит своих.

## Приёмка

```
cargo test --manifest-path acceptance/Cargo.toml
```

Тесты спрашивают у cargo, что он видит (`cargo metadata`), собирают проект и даже кладут в копию
дополнительный крейт, чтобы проверить пункт 3. Править `acceptance/` нельзя.
