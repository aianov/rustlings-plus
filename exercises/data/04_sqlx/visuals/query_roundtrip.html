Путь одного запроса через sqlx

Задача вызывает запрос, пул даёт соединение, на сервер уходят текст и параметры отдельно, обратно приходят строки. Выбери первый или повторный вызов того же запроса и пройди по шагам.

sqlx::query("SELECT username FROM users WHERE id = $1")
    .bind(7_i64)
    .fetch_one(&pool)
    .await?
